*СПЛИТ*
для использования параметра TTSS (разделение фильтра EQE на транзиент/сустейн части) необходимо иметь подключенным модуль TSE. только TSE/TSE-A являются управляющими модулями для сплита, следующие добавлененные не влияют на этот параметр.


*АВТОМАТИЗАЦИЯ/ИСТОРИЯ*
- для добавления параметра в слот необходитмо нажать ctrl + клик по полю лейбла параметра
- в текущей версии реализована слотовая отдача хосту параметров для автоматизации по причине разросшегося пула параметров (в том числе из-за неорганиченного количества модулей, в каждом из которых свой набор параметров). поэтому, для тех, кто планирует пользоватся данным плагином настоятельно рекомендую пользоваться внутренними анду-реду или же не пользоваться вовсе, а иначе при случайном прожатии анду хост вернет состояние без подключения плагина и вернуть сделанные изменения в плагине не сохранятся даже при реду. это компромис на который автор вынужден пойти из-за того, что для хоста история и параметры дял автоматизации являются единой сущностью или же автор еще не нашел способ разделить их.
