# 'MANUAL'

- длинное нажатие в плагине реализовано таким образом: длинный клик приводит к появлению промта о подтверждении действия: если отжать кнопку мыши в том же поле - действие применяется; если отжать вне поля - действие не применяется; сам выход вне поля не отменяет действие без отжимания кнопки мыши
- все скрытые органы управления индицируются бирюзовой рамкой в месте применения
- в плагине реализован не только скролл, но и драг, преимущественно для мобильных устройств
- при неактивности какого либо 'типа' цвет текста становится серым, пропадает кликабельность
- помимо основой функции кроссовер может быть использован в качестве мониторинг устройства
- мьютирование отдельных полос, в случае необходимости, можно реализовать с помощью инклюзивного режима
### `U`
- тип: `кнопка`
- undo - отменяет последнее действие
### `R`
- тип: `кнопка`
- redo - возвращает последнее отмененное действие
### `AB`
- тип: <!-- `переключатель` -->
- текущее состояние индицируется сменой цвета буквы с белого на лавандовый
- `ctrl` + `клик` по полю переключателя копирует текущее состояние во второе состояние
### `B`
- тип: `тумблер`
- является байпассом всего плагина
- длинное нажатие приводит к закрытию текущего модуля
### `C`
- тип: `текст`
- является индикатором клиппинга с автоматическим сбросом
- красный цвет буквы сигнализирует клиппинг, белый - его отстуствие
### `H`
- тип: `тумблер`
- список параметров, которые репортятся хосту
- `ctrl` + `клик` по полю лейбла 'параметра' отправляет его в `H` (хост) лист для дальнейшей работы с автоматизацией
- для выключения/включения подсказок необходимо длинное нажатие
- для очиски параметра необходимо применить длинное нажатие по имени слота (AA, AB и тд)
- перемещение параметров с помощью стрелок перемещения работает внутри плагина; для хоста слоты остаются фиксированными
- **БУДЬТЕ ВНИМАТЕЛЬНЫ**: слотовая архитектура имеет одно не приятное следствие: стандартные undo/redo хоста не влияют на undo/redo плагина и при случайном прожатии может привести к потере состояния из-за отмены плагина в цепочке плагинов (потому что для хоста добавление плагина будет считаться последним действием, записанным в историю, а не ваши действия внутри плагина), и соответственно redo так же не вернет былое состояние внутри плагина

### `AUTO-SOLO`
- тип: `тумблер`

### `SOLO-MODE`
- тип: `список`
- 'EXCLUSIVE' / 'INCLUSIVE'
- позволяет выбрать поведение кнопок соло в ручном режиме (при выключенном `AUTO-SOLO`): эксклюзивный режим солирует бэнды по одному за раз, инклюзивный режим делает соло суммарным для бэндов у которых активна кнопка соло

`текст` - не кликабельный, не имеет серой заливки
`кнопка` - имеет одно состояние
`тумблер` - имеет состояние 'вкл' / 'выкл', 'открыто' / 'закрыто', индицируется лавандовой рамкой при 'вкл'

`параметр` - лейбл и диапазон значений
