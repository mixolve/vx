# VX's manual

# MAIN
- длинное нажатие в плагине реализовано одним способом: длинный клик приводит к появлению промта о подтверждении действия: если отжать кнопку мыши в том же поле - действие применяется; если отжать вне поля - действие не применяется; сам выход вне поля не отменяет действие без отжимания кнопки мыши
- все скрытые органы управления индицируются бирюзовой рамкой в месте применения
- `ctrl` + `клик` по полю лейбла параметра/переключателя отправляет параметр в `H` (хост) лист для дальнейшей работы с автоматизацией этого параметра
- `ctrl` + `клик` по полю переключателя `AB` копирует текущее состояние во второе состояние
- для выключения/включения подсказок необходимо длинное нажатие
- индикатор `С` является индикатором клиппинга с автоматическим сбросом. красный цвет буквы сигнализирует клиппинг, белый - его отстуствие
- переключатель `B` является байпассом всего плагина. длинное нажатие приводит к закрытию текущего модуля
- кнопка U - отменяет последнее действие
- кнопка R - возвращает последнее отмененное действие
- `VX by MIXOLVE` - кнопка about
- серая/зеленая полоса выше кнопки about является потенциометром, регулирующим параметры у которых есть ввод значений. списки, кнопки, переключатели не регулируются потенциометром. для активации потенциометра нужно кликнуть по лейблу параметра и увидеть индикацию в виде зеленой рамки, что означает, что этот параметр сейчас регулируется потенциометром
- `H` - список параметров, которые репортятся хосту. для очиски параметра необходимо применить длинное нажатие по имени слота (AA, AB и тд)
- перемещение параметров с помощью стрелок перемещения работает внутри плагина; для хоста слоты остаются фиксированными
- **БУДЬТЕ ВНИМАТЕЛЬНЫ**: слотовая архитектура имеет одно не приятное следствие: стандартные undo/redo хоста не влияют на undo/redo плагина и при случайном прожатии может привести к потере состояния из-за отмены плагина в цепочке плагинов (потому что для хоста добавление плагина будет считаться последним действием, записанным в историю, а не ваши действия внутри плагина), и соответственно redo так же не вернет былое состояние внутри плагина

# MULTIBAND
- модули MTOOLS, MDYN, TSE могут быть мультибенд процессорами
- помимо основой функции кроссовер может быть использован в качестве мониторинг устройства
## CROSSOVER
### все параметры:
диапазон: `20.00` - `20000.00`
- единицы: `Hz` (герцы)
- шаг: `0.01`
### `CROSSOVER 1`
- значение по умолчанию: `134.00`
### `CROSSOVER 2`
- значение по умолчанию: `523.00`
### `CROSSOVER 3`
- значение по умолчанию: `2093.00`
### `CROSSOVER 4`
- значение по умолчанию: `5000.00`
### `CROSSOVER 5`
- значение по умолчанию: `10000.00`
- переключатели `XOV-ADD` и `XOV-DEL` добавляют и удаляют последний кроссовер соотвественно
- переключатель `AUTO-SOLO` в активном состоянии позволяет при переходе по вкладкам бэндов не нажимать вручную кнопку соло, бэнды будут солироваться автоматически и эксклюзивно (по одному за раз)
- переключатель `EXCLUSIVE/INCLUSIVE` позволяет выбрать поведение кнопок соло в ручном режиме (при выключенном `AUTO-SOLO`): эксклюзивный режим солирует бэнды по одному за раз, инклюзивный режим делает соло суммарным для бэндов у которых активна кнопка соло
- мьютирование отдельных полос, в случае необходимости, можно реализовать с помощью инклюзивного режима

# MODULE: TLS

## LISTEN
- блок может быть использован не только в качестве мониторинг средства, но и как средство выбора канала аудио трека и его расположения
- переключатели - взаимоисключающие
- `LС` - левый канал в центре; `RС` - правый канал в центре; `MС` - мид компонента в центре; `SС` - сайд компонента в центре; `LL` - левый канал в левом канале; `RR` - правый канал в правом канале; `MM` - не активное состояние; `SS` - сайд компонента в стерео
- режимы `MС`, `SС`, `SS` скомпенсированы на 6 дб (минус)
- состояние при отжатых переключателях (по умолчанию) является байпасом блока

# MODULE: EQL
## PRESET PANEL
- `AD` - добавить новый пресет с текущими настройками
- `SV` - сохранить выбранный пресет в файл
- `RN` - переименовать выбранный пресет
- `DF` - установить выбранный пресет в качестве пресета, загружаемым по умолчанию. лавандовый акцент (рамка)сигнализирует о том, что выбранный пресет является пресетом, загружаемым по умолчанию
- `DL` - удалить выбранный пресет
## FILTER PANEL
- `AD` - кнопка добавления фильтра. длинное нажатие приводит к удалению всех фильтров
- `SP` - кнопка сортировки фильтров по `PLACE`
- `SF` - кнопка сортировки фильтров по `FREQUENCY` (частоте)
- `SD` - кнопка сортировки фильтров по `PLACE` и `FREQUENCY`. именно в таком порядке
